# Gemini Image Generation Prompts for Human Evolution Persona

Use these prompts with Gemini to create educational images related to human evolution topics for children (ages 8-14).

## General Human Evolution

### Evolution Timeline
```
Create an educational illustration showing the timeline of human evolution from early primates to modern humans. Include Australopithecus, Homo habilis, Homo erectus, Neanderthals, and Homo sapiens. Make it colorful and child-friendly with simple labels. Style: educational, cartoon-like, suitable for ages 8-14.
```

### Human Evolution Overview
```
Design a simple, colorful diagram showing how humans evolved from our primate ancestors. Include key changes: walking upright, brain development, tool use. Make it engaging for school children with friendly illustrations. Style: educational infographic, bright colors, clear labels.
```

## Early Humans & Ancestors

### Lucy (Australopithecus)
```
Create an illustration of Lucy (Australopithecus afarensis) showing her walking upright. Make it friendly and educational for children. Include her small brain size and ape-like features but human-like walking. Style: cartoon, educational, child-friendly.
```

### Early Human Ancestors

## Format Specifications

When generating images, specify:
- **Format**: PNG or JPEG (high resolution, at least 1920x1080)
- **Style**: Educational, cartoon-like, child-friendly (ages 8-14)
- **Colors**: Bright, engaging colors
- **Text**: Include simple labels if needed
- **Background**: Clean, uncluttered background

## Usage Tips

1. **Be Specific**: Include age group (8-14), style (cartoon/educational), and key elements
2. **Request Multiple Versions**: Ask for variations to choose the best one
3. **Specify Dimensions**: Request specific sizes if needed (e.g., 1920x1080 for display)
4. **Iterate**: Refine prompts based on results
