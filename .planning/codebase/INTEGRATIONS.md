# External Integrations

**Analysis Date:** 2026-02-05

## APIs & External Services

**Avatar Platforms:**

1. **Tavus CVI (Conversational Video Interface)**
   - What it's used for: AI avatar conversations with real-time video/audio streaming
   - SDK/Client: Custom integration via fetch (no npm package)
   - Base URL: `https://tavusapi.com/v2/`
   - API Key: `process.env.TAVUS_API_KEY`
   - Persona ID: `process.env.TAVUS_PERSONA_ID`
   - Implementation: Serverless functions in `api/tavus/`
   - Endpoints:
     - `POST /conversations` - Create conversation with persona
     - `POST /conversations/{id}/end` - End active conversation
     - `GET /conversations` - List all conversations
     - `GET /personas/{personaId}` - Get persona details with tools

2. **HeyGen Interactive Avatar (LiveAvatar)**
   - What it's used for: Interactive avatar video with text/voice input
   - SDK: `@heygen/liveavatar-web-sdk` v0.0.9
   - API Key: `process.env.HEYGEN_API_KEY`
   - Base URLs:
     - Token creation: `https://api.liveavatar.com/v1/sessions/token`
     - Session start: `https://api.liveavatar.com/v1/sessions/start`
     - Session stop: `https://api.liveavatar.com/v1/sessions/stop`
   - Configuration:
     - Avatar ID: `process.env.HEYGEN_AVATAR_ID` (513fd1b7-7ef9-466d-9af2-344e51eeb833)
     - Voice ID: `process.env.HEYGEN_VOICE_ID` (e59787e949bd43e9ad4bef693e6b8c8e)
     - Context ID: `process.env.HEYGEN_CONTEXT_ID` (0594f8e4-c890-44dc-a5f4-113248958449)
   - Implementation:
     - `api/liveavatar/create-session.mjs` - Token and session initialization
     - `api/liveavatar/stop-session.mjs` - Session cleanup
     - `src/components/LiveAvatarManager.jsx` - React wrapper

**Auth Provider:**
- Supabase Auth (built on Postgres + JWT)
  - Implementation: `src/config/supabase.js`
  - Token flow:
    - Supabase signs user in → JWT tokens
    - Custom backend refresh endpoint: `POST /api/auth/refresh`
    - Tokens stored in localStorage (accessToken, refreshToken)
  - OAuth callback: `src/components/AuthCallback.jsx`
  - Token refresh: `src/utils/tokenRefresh.js`
  - Session persistence: Via localStorage and Supabase auto-refresh

**Custom Token Handling:**
- Manual refresh token endpoint: `process.env.REACT_APP_NODE_API_URL + /api/auth/refresh`
- Bearer token injection in `authenticatedFetch()` utility
- Automatic token refresh on 401/403 responses
- Logout clears Supabase session + localStorage tokens

## External API Calls

**Authentication Flow:**
1. User login → Supabase Auth (`supabase.auth.signInWithPassword`)
2. Receive JWT token
3. Store in localStorage
4. Attach to requests via `authenticatedFetch()`
5. On expiry: Call `/api/auth/refresh` with refresh token
6. Receive new accessToken

**Avatar Conversation Flow (Tavus):**
1. Frontend POST `/api/tavus/create-conversation` with personaId
2. Serverless function calls `https://tavusapi.com/v2/conversations`
3. Tavus creates conversation, generates Daily.co room URL
4. Returns URL to frontend
5. Frontend joins Daily.co call with `@daily-co/daily-js`
6. WebRTC streams avatar video/audio
7. On end: POST `/api/tavus/end-conversation` to Tavus API

**Avatar Session Flow (HeyGen):**
1. Frontend POST `/api/liveavatar/create-session` with userId
2. Serverless function:
   - Calls `https://api.liveavatar.com/v1/sessions/token` with HeyGen API key
   - Receives session token + server URL
   - Calls `https://api.liveavatar.com/v1/sessions/start` to begin session
3. Returns token + server URL to frontend
4. Frontend connects via HeyGen SDK with LiveKit client
5. Real-time data channel for messages (handled by LiveKitEventManager)
6. On end: POST `/api/liveavatar/stop-session` to stop session
